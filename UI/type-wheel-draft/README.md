# Type shell and click wheel: draft 1 (2026-11-22)

`type-wheel.html` is a single self-contained page (it loads Space Grotesk and Space Mono from Google Fonts; nothing else). Open it in a browser. It is a mock-up of the
Type shell's list screens with a click-wheel column, at the same scale as the boards in `UI/type-shell-draft/` (the real 320 x 240 screen at 2x). It is not built into
any image and no C has been written for it; the design notes and open questions are at the bottom of the page and in plan7.md ("Wheel hybrid, draft 1").

Layout A is the pad, keys and trackball (full-width list, side panel, ink hint bar). Layout B draws a wheel on the screen for touch. Click the screen, then use the
arrow keys, Enter, Esc, H, Space; or drag round the ring. The art is original (the covers are CSS shapes); the accent and fonts are the Type shell's.
