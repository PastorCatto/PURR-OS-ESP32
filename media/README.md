# media/

Source artwork kept for reference.

## `BB OS 10.3.02.2876 ICONS.zip`

A BlackBerry OS 10.3.0.2876 icon pack.

**The only assets PURR OS uses from it are BlackBerry OS icons** — the native
BlackBerry system-app icons (Calculator, Clock, Settings, File Manager) that
the launcher shows, downscaled to 32x32 and compiled into
`source/modules/common/purr_icons.c`. Nothing else in the archive is used or
embedded anywhere in the firmware.

The archive also contains icons for third-party apps and brands. Those are not
used by PURR OS.
